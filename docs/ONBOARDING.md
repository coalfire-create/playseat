## 2. 전체 루프 돌려 보기

터미널 2개.

```bash
# 터미널 1 — 허브 서버. 동승자 웹앱도 같이 서빙합니다
cd hub-server && ./gradlew run

# 터미널 2 — 차량 앱 목(mock). 차량 앱 없이 개발하기 위한 장치입니다
node demo/mock-car.mjs
```

브라우저에서 `http://localhost:8080` 을 엽니다.

1. 좌석 칸을 눌러 참여합니다 (이름 입력)
2. 곡을 검색해 추가합니다 — **자기 차례일 때만** 됩니다. 아니면 거절 토스트가 뜹니다
3. 터미널 2에서 `d` 를 누르면 주행 상태로 바뀝니다. 폰이 조작 권한을 받는 구간입니다
4. `1`~`5` 로 좌석 착석을 토글합니다. 하차시키면 그 좌석의 미재생 곡이 큐에서 사라집니다

이게 CP1·CP2가 요구하는 동작입니다. 이미 돌아갑니다.

## 4. 당신의 작업

### 먼저 할 것 — 곡 검색 교체
`hub-server/.../SearchStub.kt` 가 고정 목록 20곡을 돌려주는 스텁입니다.
실제 메타데이터 검색으로 교체하세요. 반환 형식은 그대로 유지합니다
(`search.result` · `{ title, artist, durationMs, externalId }`).

차량 앱은 검색을 모릅니다. `queue.add` 로 넘어온 `title`/`artist` 만 해석합니다.
그래서 검색 소스를 무엇으로 바꾸든 차량 앱은 건드릴 필요가 없습니다.

### 그다음 — `passenger-web` 을 당신 것으로
현재 `index.html` 은 동작하는 기본형입니다. 레이아웃·스타일·상호작용을 가져가세요.
단 두 가지 원칙은 유지해야 합니다.

1. **스스로 판단하지 않습니다.** 화면은 `state.sync` 를 그대로 그립니다.
   턴 순서나 스킵 과반을 폰에서 계산하면 차량 판정과 어긋납니다.
2. **낙관적 업데이트 금지.** 요청을 보내고 다음 `state.sync` 를 기다립니다.
   차량이 거절할 수 있어서, 먼저 UI에 반영하면 되돌려야 합니다.

### 이후
- `demo/` — Pleos Emulator Virtual Console 자동 조작, 시나리오 녹화 스크립트
- 시연 영상 편집·자막, 화면 시안, 숏폼

전체 일정과 체크포인트는 `docs/WORKPLAN.md` 에 있습니다.

## 5. 건드리지 않는 것

| 경로 | 담당 |
|---|---|
| `car-app/` | 차량 앱 담당 |
| `hub-server/`, `passenger-web/`, `demo/` | **당신** |
| `contract/` | 공동 — 변경은 양쪽 승인 필수 |

브랜치는 `feat/hub-*`, `feat/web-*`, `feat/demo-*` 로 만들고 PR로 병합합니다.
`main` 직접 푸시는 막혀 있지 않지만 쓰지 않습니다.

## 6. 계약서를 먼저 읽으세요

`contract/protocol.md` 가 차량 앱과 당신 코드의 **유일한 접점**입니다.
현재 v0.2이며, 맨 앞의 **구현 상태표**를 반드시 보세요.

`mode`, `landing`, `queueTotalMs`, `drive.album` 은 설계만 합의된 **미구현** 항목입니다.
차량 앱이 아직 내려보내지 않으므로 이 필드에 의존하는 코드를 먼저 쓰지 마세요.
폰은 해당 필드가 `undefined` 인 상태를 정상으로 다뤄야 합니다.

계약을 바꿔야 하면 혼자 고치지 말고 알려 주세요. 조용히 바뀌면 양쪽이 동시에 깨집니다.
