## 남은 검증 🔴

| 할 일 | 담당 |
|---|---|
| ETA — 내비에 경로를 넣고 `onDrivingInfo` 수신 확인 | 구성원 A |

`NaviHelper` 연결과 리스너 등록까지는 확인했고, 실제 경로를 주행하며 값을 받는
것만 남았습니다. 에뮬레이터 기본 위치가 Mountain View 라 국내 경로를 만들지
못했습니다. `ai.umos.maps.android.navigation.app.SET_DESTINATION` 인텐트로
접근할 수 있습니다.

ETA 는 '도착 5분 전 랜딩' 과 '도착 맞춤 편성' 두 기능의 입력입니다. 목·Fake
신호원에서는 ETA 가 실제로 흐르므로 두 기능 모두 시연되고 단위 테스트도 돌아갑니다.
실차 내비에서 값을 받는 부분만 미검증이며, README 와 계약서에 '부분 동작' 으로
적어 두었습니다. 목적지가 없으면 도착 맞춤 편성은 네 필드를 모두 비워 조용히
사라지므로, 시연에서 빠져도 다른 기능이 깨지지 않습니다.

ETA 가 없으면 도착 맞춤 편성은 화면에 아무것도 내놓지 않습니다. 그래서 있는 척
하는 대신 **주입 통로를 공개**했습니다.

```bash
adb shell am broadcast --user 10 -a dev.semicolon.playseat.DEMO_ETA --ei seconds 180
```

음수를 주면 해제됩니다. 주입값은 1초마다 스스로 줄고, 내비가 실제 경로를 주기
시작하면 그 순간부터 무시됩니다. **시연 영상 자막에도 주입했다는 사실을 적습니다.**
자세한 내용은 [VERIFY.md](VERIFY.md) 의 'ETA — 미검증' 절에 있습니다.
