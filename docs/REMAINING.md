## 1. 검증 — 대부분 끝났습니다 🟢

| 항목 | 결과 |
|---|---|
| AVD 생성 · 앱 설치 · 실행 | 완료 |
| 퍼미션 8종 | 전부 `prot=normal`, 설치 즉시 부여 |
| **`CAR_SEATS` 실제 수신** | **5석 지원 확인, 좌석 변화에 UI 실시간 반응** |
| 기어 → 주행 모드 전환 | 확인 |
| 충전 → 라운지 모드 발동 | 확인 |
| ETA (`NaviHelper`) | 연결·리스너 등록까지 확인, **경로 주행은 미검증** |

**기획의 가장 큰 리스크였던 좌석 착석 감지가 실제로 동작합니다.**
자세한 절차와 수치는 [`VERIFY.md`](VERIFY.md) 에 있습니다.

검증 과정에서 두 가지를 고쳤습니다.

1. **SDK 의 착석 Boolean 이 뒤집혀 있었습니다.** 그대로 썼으면 앉으면 빠지고
   비면 들어오는 정반대 동작이었습니다. 어댑터에서 보정했습니다.
2. **주행 중 앱이 통째로 가려졌습니다.** AAOS 주의분산 제한입니다.
   `distractionOptimized` 선언을 넣어 주행 중에도 화면이 유지됩니다.

### 남은 검증

| 할 일 | 담당 |
|---|---|
| ETA — 내비에 경로를 넣고 `onDrivingInfo` 수신 확인 | 이정한 |

에뮬레이터 기본 위치가 Mountain View 라 국내 경로를 만들지 못했습니다.
`ai.umos.maps.android.navigation.app.SET_DESTINATION` 인텐트로 접근할 수 있습니다.
ETA 는 '도착 5분 전 랜딩 트랙' 기능에만 쓰이므로, 안 되면 그 기능만
시연에서 빼고 설계로 설명하면 됩니다. 기획 전체가 걸린 항목은 아닙니다.
