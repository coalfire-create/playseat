# 화면 시안

Pleos Connect 에뮬레이터(v2.1.0)와 실제 동승자 웹앱에서 **직접 찍은 화면**입니다.
목업이 아니라 돌아가는 앱이며, `node demo/shots.mjs` 로 같은 장면을 다시 찍을 수 있습니다.

차량 화면은 1688×1210 (에뮬레이터 2560×1440 중 앱 영역), 폰 화면은 390×844 @2x 입니다.

## 디자인 근거

색·면 나누는 방식·타이포는 Pleos Connect 시스템 UI(차량 설정 화면)를 캡처해
픽셀에서 뽑은 값입니다. 둥근 카드를 띄우지 않고 1px 헤어라인으로 나눈 평면 셀을
쓰며, 파랑(#1262F5)은 '지금 활성' 인 값 하나에만 씁니다.

헤드유닛은 앱 하나를 쓰는 기기가 아닙니다. 내비·전화·차량설정 사이를 계속
오가기 때문에, 우리 앱만 다른 언어를 쓰면 '나중에 얹은 것' 으로 보입니다.
동승자 폰도 같은 언어를 쓰는 이유가 같습니다.
