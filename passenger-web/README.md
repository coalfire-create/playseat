# passenger-web

동승자 웹앱. **설치가 필요 없는 것이 핵심 전제**입니다.
차량 화면의 QR을 스캔하면 폰 브라우저에서 바로 열립니다.

빌드 과정이 없는 정적 파일이며 `hub-server` 가 서빙합니다.
`http://localhost:8080/?s=<sessionId>`

## 현재 구현 (기본형)

좌석 배치도·좌석 참여, 턴 표시, 곡 검색·추가, 큐, 스킵 투표·♥, 주행/정차 배너.
`deviceId` 는 `localStorage` 에 저장해 재접속 시 좌석에 자동 복귀합니다.

## 설계 원칙

- **스스로 판단하지 않습니다.** 화면은 차량이 보낸 `state.sync` 를 그대로 그립니다.
- **낙관적 업데이트 금지.** 차량이 요청을 거절할 수 있으므로, 보내고 나서 다음
  `state.sync` 를 기다립니다. 먼저 UI에 반영하면 되돌려야 합니다.
- 주행 중(`driveState === "DRIVING"`)에는 운전자 화면이 잠기고 조작 권한이 이 폰으로
  넘어옵니다. 이때 UI를 더 넓게 쓰는 것이 의도된 동작입니다.
